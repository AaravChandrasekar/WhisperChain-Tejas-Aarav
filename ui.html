WhisperChain+

Each browser tab is signed in as its own user, so open one tab per person you want to play.

Sign in

The first admin is made on the command line: python create_admin.py <name>

Create an account

Makes your key pair on this machine and asks an admin to approve you. Sign in once approved.

Roles:

Send an anonymous compliment

Get your anonymous credential once, then send one message per round.

Inbox

Messages are decrypted and verified in this tab. Flag one to send it to the moderators.

Flagged messages

Dismiss false reports, or freeze the anonymous sender of an abusive one.

Accounts and rounds

Approve new accounts. Opening a round closes the current one; senders get one message per round.

Audit log

Role-level events only, never usernames. Viewing it is logged too.
